# maxxen.ai

**Bespoke websites, web applications, and digital experiences — forged for brands with soul.**

A dark-fantasy "Arcane Canvas" landing page for maxxen.ai, a founder-led web & app development atelier.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4 with custom OKLCH design tokens
- Framer Motion
- Google Fonts: Cormorant Garamond (serif) · Pinyon Script (script) · Inter (sans)

## Run

```bash
npm install
npm run dev
```
